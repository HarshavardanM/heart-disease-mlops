## Project Overview

This project demonstrates an end-to-end machine learning workflow using the UCI Heart Disease dataset. It includes exploratory data analysis, feature preprocessing, model development and evaluation, MLflow experiment tracking, a FastAPI prediction service, Docker packaging, automated API tests, and GitHub Actions continuous integration.

**Best test results:** Accuracy 86.89%, Recall 92.86%, and ROC-AUC 95.67% on the held-out Cleveland test set.
